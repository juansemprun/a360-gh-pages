Hello👋
This week we shipped several improvements to our core feature **"On-page analysis (OPA)"**. These updates make it easier to perform detailed analysis and improve your website performance.

- **Improved event creation** : When creating an event in the OPA, you can now add the device type 📱💻
  <Image src={image1} alt="Improved event creation" />
- **Improved scoping in the OPA**: You can now use the `datalayer`, URL's `querystring` or `queryhash` for more precise filtering. This update works retroactively on the data as long as the datalayer is already added to Air360😉
  <Image src={image2} alt="Improved scoping in the OPA" />
- **Improved exposure rate** : We have upgraded the exposure rate formula using some advanced math 🚀 This delivers more accurate readings especially for longer pages and is fully retroactive! 🎉
