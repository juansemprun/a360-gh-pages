<Badge variant="noLink" className="m-0">
  <span>Améliorations</span>
</Badge>

- Il existe désormais un menu dédié pour les propriétés du datalayer dans l'interface de création d'événements.
- Amélioration du lanceur pour le nouvel OPA
  - Les domaines avec le plus de trafic apparaissent automatiquement en premier
  - Vous pouvez ajouter des domaines aux favoris en utilisant l'icône favori
- Limite de 100K sessions à l'affichage
  - Nous avons précédemment introduit une limite d'affichage de 100K sessions dans les parcours utilisateurs pour éviter les problèmes de performance du navigateur lors de la gestion d'un grand nombre de sessions.
  - Cette limite affecte uniquement le nombre de sessions affichées dans le navigateur—elle n'impacte pas l'analyse, qui inclut toujours toutes les sessions dans la plage de dates sélectionnée.
