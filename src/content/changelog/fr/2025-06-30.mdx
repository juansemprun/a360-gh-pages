Bonjour👋

Excellente nouvelle pour les boutiques Shopify !⭐️ Nous venons de mettre à jour notre application Shopify pour résoudre l'un des plus grands défis de suivi sur les boutiques Shopify : **capturer les événements sur des pages critiques comme le paiement !**
Shopify a historiquement restreint l'utilisation de pixels de suivi sur les pages à fort impact, rendant difficile la capture de données précieuses sur le comportement des clients.

Avec cette version, nous avons introduit une nouvelle méthode qui permet à l'application Air360 de :

- 🔍 Capturer plus d'événements clients dans votre boutique
- 🛒 Suivre les actions sur des pages auparavant restreintes — y compris le paiement

Cette amélioration élimine les principaux angles morts de votre suivi sans nécessiter de modifications à votre configuration existante.
Pour les pages de paiement, cela signifie que bien que vous ne puissiez toujours pas utiliser notre analyse sur la page (OPA), vous pouvez analyser les événements de paiement dans les tunnels de conversion, les parcours utilisateurs et les tableaux de bord personnalisés !
