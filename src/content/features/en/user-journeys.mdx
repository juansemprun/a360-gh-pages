faqs:
  - question: What are User Journeys?
    answer: A user journey is the complete path a visitor takes on your site, from entry to final outcome. Whether that's a purchase, signup, or another key action. It captures every interaction, detour, and exit, showing how users move through your site.
  - question: Why use User Journey?
    answer: User Journey reveals how visitors actually behave, where they get lost or drop off, and hidden opportunities to guide them toward conversion. Reduce friction, optimize the paths that drive results, and make decisions based on real user behavior.
  - question: How is User Journeys different from Funnel Analysis?
    answer: While Funnel Analysis tracks predefined conversion paths, User Journeys reveal organic, unexpected paths users actually take, helping you discover new optimization opportunities and understand real user behavior.
  - question: Is it limited to only analyzing users' page journey?
    answer: No. You can analyze journeys using any user behavior, like button clicks, rage clicks, errors, and more. What that means, is you can of course conduct a macro analysis to see how users move between pages, but also conduct micro analysis to understand how they navigate within a specific page.
  - question: How does analyzing user journeys help make better business decisions?
    answer: See how users actually navigate your site, then prioritize the fixes that matter most. Spot high-performing paths and replicate them for other segments. Identify frequent drop-off points and remove the barriers causing them. User Journey turns behavior data into clear actions that improve conversions and business outcomes.
